# IPL Insights Dashboard using Python & Streamlit
An interactive IPL analytics dashboard built with **Python**, **Streamlit**, and **Machine Learning**. The application analyzes historical IPL match data through interactive visualizations and predicts match outcomes using Logistic Regression.
## Features
- 📊 Interactive IPL Dashboard
- 🏆 Team Performance Analysis
- ⭐ Top 10 Player of the Match Statistics
- 🏟️ Venue-wise Match Analysis
- 📈 Matches Per Season Analysis
- 📉 Team Win Percentage Visualization
- 🤖 Match Outcome Prediction using Logistic Regression
- 🎯 Team-wise Interactive Filtering
## Tech Stack
- Python
- Streamlit
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
## Dataset
- IPL Matches Dataset (`ipl-matches.csv`)
